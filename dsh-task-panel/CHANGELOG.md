# Changelog

## 0.6.1 — 2026-11-06

- 新增：Git 状态与分支切换联动功能。
  - 右上角入口常驻显示未提交更改数量徽标（如 `±3`）；
  - 任务面板展开卡片中新增 Git 状态条，显示当前分支、更改文件数及 `+新增 / -删除` 行数；
  - 新增分支切换下拉菜单（Branch Switcher），支持查看所有本地分支、关键字过滤搜索及一键切换（checkout）；
  - 明确点击「查看 Diff ›」/「打开 ›」按钮时才呼出侧边栏 Git 源码管理面板；
  - 新增插件服务端 `/dsh-task-panel/git-branches` 与 `/dsh-task-panel/git-checkout` 路由，提供双重高可用兜底。

## 0.6.0 — 2026-11-05

- 从 UI Beautify 抽离独立轻量版任务面板 `dsh-task-panel`。
- 精简设置页面，仅保留专属任务面板与消息气泡设置项。
- 任务进度、输出交付物、工具调用三大模块解耦与独立开关。
